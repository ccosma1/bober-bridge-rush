# Bober Bridge Rush

Phone-first bridge crowd rush. Drag between far math gates while the red wave is still on you. Chapter 1, The Dam Runs Dry, runs 1-1 Pine Bridge through 1-10 Last Gasket.

Fan game. Unofficial. The in-game currency is $BOBER. Nothing here is real money.

Open `index.html` through a static server. Three.js r170 loads from the jsDelivr pin in the import map. There is no build step.

```bat
START.bat
```

That serves http://127.0.0.1:8792/?v=br19

Build tag: br19
